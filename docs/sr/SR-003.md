# SR-003 타이어 (규격 기록 → 쿠팡 사진 상품 · 교체 기록)

- 요청: 2026-11-28 사장님 피드백 8번 "우리 약점이 타이어가 없어"
- 상태: 보류 (2026-11-28 사장님: 전 차종을 다 맞출 방법이 없으면 패스)
- 규모: 중간 (개발팀 2~3개)
- 원래 SR-003(콘텐츠·타이어·부품 사진)은 너무 커서 셋으로 나눔: **SR-003 타이어(이번)**, SR-005 관리 콘텐츠, SR-006 부품 사진.

## 약점 먼저
- **차종별 순정 타이어 규격 데이터가 없어요.** 같은 차도 트림·휠(16·17·18인치)마다 규격이 달라서, 차만 보고 규격을 정하면 틀릴 수 있어요. 그래서 **사장님이 타이어 옆면 숫자(예: 225/45R17)를 한 번 입력**하는 방식으로 해요. 입력 한 번이 귀찮은 게 약점.
- **"몇 km마다 교체" 숫자는 공식 출처를 아직 확인 못 했어요(확인 필요).** 개발 중 조사 담당이 제조사·공공기관 출처를 찾으면 진행 막대를 그리고, 못 찾으면 막대 없이 "교체한 날·거리 기록 + 마모 확인법"만 보여 줘요. 지어낸 주기는 안 넣어요.
- 타이어는 비싸고(개당 10만 원 안팎, 확인 필요) 장착비가 따로 들어요. 공임나라 타이어 장착비 데이터는 없어서 **이번엔 금액 계산(아낀 돈)에 넣지 않아요.**
- 쿠팡 검색 결과에 같은 규격의 다른 크기(예: 225/45R18)가 섞일 수 있어 규격 문자열로 한 번 더 거릅니다. 쿠팡 API 한도 때문에 화면이 보일 때만 불러요.

## 공통 원칙
- 글 최소, 390px 줄바꿈, 전문용어 없이(“트레드” 대신 “홈 깊이”), 빈 항목 숨김.
- 등록한 차를 다시 고르게 하지 말 것. 규격은 한 번 입력하면 차에 저장.
- 쿠팡 상품 근처 파트너스 고지 유지. 다른 앱 디자인 복제 금지.
- 저장 위치: 기존 교체 기록(records)에 `tire` 항목으로 — 계정 저장 칸을 새로 만들지 않음(DB 변경 없음). 번호판 등 개인정보 없음.

## 항목

### 1. 정비 탭에 '타이어' 줄
- 부품 목록 맨 아래에 타이어 한 줄(다른 부품과 같은 모양).
- 규격이 없으면: "타이어 옆면 숫자를 적으면 맞는 타이어를 찾아 드려요" + [규격 적기].
- 규격이 있으면: "225/45R17 · 교체 기록 없음" 또는 "24.03.01 교체". 출처가 확인된 주기가 있을 때만 진행 막대.
- 펼치면: 쿠팡 사진 상품(같은 규격만, 최대 3개) + [오늘 교체했어요] [날짜 직접 입력] [규격 바꾸기].
- 완료 기준: K3 BD 등록 → 타이어 규격 225/45R17 입력 → 새로고침해도 남아 있음 → 펼치면 225/45R17 상품만 보임(로컬에서 쿠팡 막히면 '확인 필요').

### 2. 규격 입력 화면(작은 창)
- 숫자 3칸(폭 225 / 편평비 45 / 휠 17)과 예시 그림 한 장: 타이어 옆면 어디에 숫자가 있는지, 운전석 문 안쪽 스티커에도 있다는 것. 그림은 우리가 직접 그린 단순한 선 그림(SVG).
- 흔한 값 칩(205/55R16, 225/45R17, 235/55R19 등)을 눌러 빨리 넣기 — 칩 목록은 국산 인기 차 기준, "내 차 규격은 옆면을 꼭 확인하세요" 한 줄.
- 잘못 넣는 것에 대한 막기는 만들지 않음(숫자 범위 정도만).

### 3. 쿠팡 타이어 검색
- 기존 /api/coupang-search 에 타이어 검색 추가: 검색어 "225/45R17 타이어", 결과에서 상품명에 규격(225/45R17, 2254517 등 표기 변형)이 있는 것만.
- 사계절 위주. 겨울용(스노우·윈터)은 11~2월에만 앞에 보이게 할지 → 판단 필요(기본: 섞지 않고 사계절만).
- 같은 시간당 한도 보호 장치 사용.

### 4. 마모 확인법 한 줄 (i)
- (i)를 누르면: 홈 깊이 법적 기준과 동전으로 재는 법. **출처가 확인된 내용만**(예: 자동차관리법 관련 규칙·한국교통안전공단). 조사 담당이 출처 URL을 SR 결과에 적음. 못 찾으면 이 항목은 빼고 보고.

### 5. 처리방침
- 저장하는 것에 '타이어 규격' 추가(이 폰 + 로그인 시 계정의 교체 기록과 함께).

## 범위 밖
- 차종별 순정 규격 자동 채우기(데이터 출처 확보 후 별도 SR)
- 타이어 장착비·아낀 돈 계산, 근처 타이어 가게 지도 필터
- 홈 화면·계산기에 타이어 넣기

## 일정
- 승인 후 파이프라인 1회. 출처 조사 1명 추가. 2~3시간 예상(확인 필요). 통과하면 바로 오픈.

## 나머지 (분석만, 다음 SR)
