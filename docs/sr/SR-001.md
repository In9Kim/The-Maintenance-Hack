# SR-001 화면 정리 (빈 공간·정비소 목록·모순 문구·리콜 하단)

- 요청: 2026-11-28 사장님 폰 스크린샷 피드백 1~6번
- 상태: 승인됨 (2026-11-28)
- 규모: 작음. 탭 구조 개편(더보기 메뉴)은 SR-002에서. 이번엔 기존 화면 안에서만 정리.

## 공통 원칙
- 글 최소, 휴대폰 390px에서 단어 중간 줄바꿈 없게, 전문용어 없이, 빈 항목 숨김.
- 등록한 차를 다시 고르게 하지 말 것.
- 쿠팡 상품이 보이는 곳 근처의 파트너스 고지(AFFILIATE_TEXT)는 반드시 유지.
- SEO에 필요한 내용(자주 묻는 질문, JSON-LD)은 지우지 말고 덜 눈에 띄게.

## 항목

### 1·5. 화면 아래 바닥글과 빈 공간
- 현상: 내용이 짧은 화면(홈, 정비소 끝)에서 내용과 바닥글 사이에 큰 빈 공간. 바닥글(© 2026 정비핵 · 데이터 출처·이용 안내 · 가격은 참고용 추정치예요)은 아무도 안 봄.
- 요구: 바닥글을 없애고 빈 공간이 생기지 않게. '데이터 출처·이용 안내'·'개인정보 처리방침'은 마이 > 안내 목록에 이미 있으니 거기로 충분(없으면 추가). '가격은 참고용 추정치'는 가격이 나오는 곳에 이미 안내가 있는지 확인하고, 없으면 가격 근처 (i) 말풍선으로.
- 완료 기준: 홈·정비소·마이·견적서 화면 390x844에서 마지막 내용 아래 하단 탭까지 불필요한 빈 공간 없음.

### 2. 정비소 목록 30곳 → 가까운 몇 곳 + 더 보기
- 현상: '지난번 위치 기준 20km 안 30곳'을 한 번에 다 보여 줌.
- 요구: 가까운 5곳만 먼저, 아래 '더 보기(5곳씩)'. 머리 문구도 짧게(예: '가까운 공임나라'). 카카오맵·네이버지도 목록 방식을 참고하되 디자인 복제 금지.
- 완료 기준: 첫 화면에 5곳 + 더 보기, 눌렀을 때 5곳씩 늘어남, 길찾기·전화·상세 그대로 동작.

### 3. 정비소 화면 아래 '맡기기 전에 부품값부터 확인하세요' 상자
- 요구: 삭제.

### 4. 마이: '당장 교체할 게 없어요'인데 쿠팡 상품이 펼쳐져 있음 (모순)
- 현상: 머리 문구는 교체할 게 없다는데, 첫 부품(와이퍼, 6개월 남음)이 펼쳐져 쿠팡 상품 2개가 보임.
- 요구: 처음 들어올 때 부품을 자동으로 펼치지 않기(급한 부품이 있을 때만 그 부품을 펼치는 건 허용). 여유 있는 부품(ok 상태)을 펼치면 쿠팡 상품 목록 대신 짧은 한 줄('N개월 남았어요. 때가 되면 알려 드릴게요' 류) + 기존 버튼(오늘 교체했어요·날짜 직접 입력·규격·가격 자세히). 곧/지남 상태 부품은 지금처럼 상품 표시.
- 완료 기준: 교체할 게 없는 차로 마이를 열면 상품이 하나도 안 보임.

### 6. 차 리콜 페이지(/cars/[carId]/recalls) 아래쪽이 안 읽힘
- 현상: 리콜 목록 아래 '소모품 교체 비용 보기 카드(제목이 '보기'에서 꺾임)', '전체 리콜 목록 보기', '자주 묻는 질문', 긴 출처 문단이 이어져 있는데 눈에 안 들어오고 읽히지도 않음.
- 요구: 비용 카드는 한 줄 제목(줄 꺾임 없게)과 짧은 문구로. 자주 묻는 질문은 접힌 상태 유지하되 덜 크게. 출처 문단은 한 줄('출처: 자동차리콜센터 외 2곳') + (i)를 누르면 자세히. 전체적으로 리콜 목록이 주인공이 되게.
- 완료 기준: 390px에서 아래쪽이 한눈에 정리돼 보이고 출처 긴 문단이 기본으로 안 보임.

## 범위 밖 (SR-002·003)
- 탭 구조 A안(홈·정비·견적서·정비소·더보기), 정비 탭, 알림함, 더보기 메뉴, 콘텐츠 에이전트, 타이어, 부품 사진.

## 결과 (2026-11-28)

### 항목별 처리
- 1·5 바닥글·빈 공간: 바닥글 삭제. 홈·견적서·정비소·마이 390x844에서 끼워 넣은 빈 공간 없음. 데이터 출처·개인정보 처리방침은 마이 > 안내에 있음.
- 2 정비소 목록: 처음 5곳 + '더 보기 (5곳)', 누를 때마다 5곳씩 늘고 끝나면 버튼 사라짐. 머리글은 '○○ 근처 공임나라 N곳' 한 줄. 핀 누르면 목록이 펼쳐지고 카드가 하단 탭에 안 가림.
- 3 '맡기기 전에 부품값' 상자: /near에서 삭제.
- 4 마이: 처음 들어올 때 자동 펼침 없음. 여유 있는(ok) 부품은 'N개월 남았어요. 때가 되면 …' 한 줄 + 기존 버튼. 교체할 게 없는 차로 열면 쿠팡 링크 0개(실측).
- 6 리콜 페이지 아래쪽: 비용 카드 한 줄 제목('소모품 교체 비용', '직접 사면 아껴요 ○원 ›'), 자주 묻는 질문 작게 접힘, 출처는 '출처: 자동차리콜센터 외 2곳 (i)' 한 줄(누르면 링크·기준일·면책). 출처 링크와 FAQ·JSON-LD는 HTML에 그대로 있음.
- 검수 중 추가 수정: InfoTip 말풍선이 화면 아래쪽에서는 위로 열림, '리콜 2건' 줄바꿈이 '2건'만 떨어지지 않게.

### 남은 문제·확인 필요
- (판단 필요) 블루핸즈·오토큐 화면의 '공식센터 견적, 직접 구매하면 얼마일까요?' 상자도 같이 지워짐. SR 3은 공임나라 상자만 말함. 되살릴지 결정 필요.
- (판단 필요) 교체 주기 정보가 없는 부품(브레이크 패드·디스크·배터리 등)은 교체 기록이 있어도 펼치면 쿠팡 상품이 나옴. 처음 열 때는 0개라 완료 기준은 통과.
- (판단 필요) 바닥글 삭제로 /info·/privacy 링크가 마이에만 남음(데스크톱 노출 정책).
- 머리글 'N곳'은 전체 수, 목록은 5곳부터 보임(그대로 둠).
- 정비소 화면의 '위치는 저장하지 않습니다' 문구가 실제 동작(지난 위치를 이 폰에 저장)과 다름. SR 이전부터 있던 문제.
- 기존 문제(범위 밖): 차 리콜 페이지에서 하단 탭 '마이'에 불이 들어옴, 엔진오일 쿠팡 상품에 다른 차종 필터가 보임.
- 확인 못 함: 로그인 상태 문구(로그인 불가), '내 위치' 머리글(위치 권한 불가), 실제 카카오맵 SDK·앱 이동(localhost에서 가짜 SDK로 시험).
- 커밋 때 .claude/ 폴더는 빼야 함.
