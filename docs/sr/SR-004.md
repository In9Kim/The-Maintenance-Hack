# SR-004 정비 비용 계산기 정리 (내 차 다시 안 묻기·부품 줄이기·상품 사진)

- 요청: 2026-11-28 사장님 폰 스크린샷 (더보기 > 정비비 계산기)
- 상태: 승인(11-28)
- 규모: 작음~중간 (개발팀 2개)

## 약점 먼저
- 상품 사진은 쿠팡 검색 API로 불러와요. 고른 부품마다 한 번씩 부르므로 **사진 상품은 고른 부품 중 위에서 3개까지만** 보여 주고, 나머지는 지금처럼 검색 링크로 둬요(쿠팡 API 시간당 한도 보호). 
- 쿠팡 검색 결과가 가끔 다른 차용 상품을 섞어요(예: 엔진오일에 다른 차 필터). 엔진 이름으로 거르는 기존 장치를 같이 쓰지만 완벽하진 않아요.
- 규격 글(SAE 0W-20 …)을 접으면, 규격을 보려면 한 번 더 눌러야 해요.

## 공통 원칙
- 글 최소, 390px에서 단어 중간 줄바꿈 없게, 전문용어 없이, 빈 항목 숨김.
- 등록한 차를 다시 고르게 하지 말 것.
- 쿠팡 상품 근처 파트너스 고지(AFFILIATE_TEXT) 유지.
- 주소 ?model= ?part= 로 들어온 경우(견적서·부품 확인에서 넘어옴)는 지금 동작 유지.
- SEO용 제목·설명은 유지 (등록 안 한 사람·검색엔진은 지금과 비슷하게 보임).

## 항목

### 1. 내 차가 있으면 차종 선택 상자 숨기기
- 현상: 내 차(K3 BD, G1.6)가 이미 골라져 있는데도 '차종 선택' 상자(제조사·모델·AI로 만들기·엔진)가 그대로 크게 보여서 다시 입력받는 것처럼 보임.
- 요구: 등록한 차가 있으면 상자 대신 한 줄 카드 **"내 차 · 기아 K3 BD · G1.6 가솔린   [다른 차]"**. 여러 대 등록했으면 차 이름 칩으로 바꾸기. [다른 차]를 누를 때만 지금 상자가 펼쳐짐.
- 맨 위 설명 문단(“이번에 바꿀 소모품만 체크하세요…”)은 한 줄로 줄이기.
- 완료 기준: 내 차 등록 상태로 /calculator 를 열면 첫 화면에 제조사·모델 입력칸이 없음. [다른 차]로 바꾸기 가능.

### 2. 부품 목록 줄이기
- 현상: 부품 카드가 길고(규격 2줄) 개수가 많아 스크롤이 김.
- 요구:
  - 카드 한 장 = 이름 + 직접 살 때 금액 + 센터 추정 금액 + 한 줄(교체 주기만, 예: "15,000km·12개월마다"). **규격 글은 카드를 펼쳤을 때만**(또는 (i)).
  - 내 차가 있으면 **'갈 때 된 부품'(정비 탭에서 지남·곧)을 맨 위에 미리 체크**, 나머지는 "다른 부품 N개 더 보기"로 접기.
  - 내 차가 없으면 많이 찾는 부품 4개(엔진오일·에어컨 필터·에어클리너·와이퍼 등 데이터에 있는 것)만 먼저, 나머지는 접기.
  - 분류 제목(오일류·필터류·브레이크)은 접힌 목록 안에서만.
- 완료 기준: 390x844에서 내 차 등록 상태 첫 화면~부품 목록이 2화면 안. 카드에 규격 글이 기본으로 안 보임.

### 3. 결과의 쿠팡 링크에 상품 사진
- 현상: 결과 아래 쿠팡 링크가 글자 카드("쿠팡에서 이 규격 가격 보기 / '엔진오일 0W-20 API SP 합성유' 검색")라 상품이 안 보임. 마이·정비 탭은 이미 사진+가격 상품을 보여 줌.
- 요구: 고른 부품마다 정비 탭과 같은 **사진+이름+가격 상품 줄(LiveCoupang, 최대 2개)**. 등록한 엔진이 있으면 다른 엔진용은 거름. 상품을 못 찾으면 지금 검색 링크로 대신. 고른 부품이 4개 이상이면 위 3개만 사진, 나머지는 검색 링크.
- 오일 '필요량 ○L' 안내는 유지. 파트너스 고지는 상품 바로 위 한 번.
- 완료 기준: K3 BD + 엔진오일 고르고 결과 보기 → 사진 있는 쿠팡 상품이 보임(실측, 로컬에서 쿠팡 API가 막히면 '확인 필요'로 보고).

## 결과 (11-28)

### 항목별 처리
- 1. 내 차 숨기기: 등록한 차가 있으면 차종 상자 대신 '내 차 · 기아 K3 BD · G1.6 가솔린 [다른 차]' 한 줄. 2대 이상이면 칩(고른 칩에 엔진 표시), [다른 차]로 상자 펼침·'내 차로 돌아가기' 가능. 맨 위 설명은 한 줄.
- 2. 부품 목록: 카드 = 이름·금액·교체 주기 한 줄, 규격은 (i) 안. 갈 때 된 부품은 맨 위에 미리 체크하고 '3개월 지남'처럼 주황색 표시(정비 탭과 같은 글자), 나머지는 '다른 부품 N개 더 보기'로 접음. 차가 없으면 많이 찾는 4개만 먼저.
- 3. 결과 상품 사진: 고른 부품 위 3개는 사진·이름·가격 상품(최대 2개), 4번째부터는 '이름 · 쿠팡 가격 ›' 한 줄. 쿠팡 API는 결과 보기를 누르거나 결과까지 내렸을 때만 부름. 다른 엔진·다른 부품(오일필터·워셔액 등) 상품은 거름. 필요량 안내·파트너스 고지(한 번) 유지.
- 재확인 P2 '내 차로 돌아가기·같은 칩 다시 누르면 미리 체크가 풀림': 고침. 내 차를 고를 때마다 미리 체크가 다시 돌도록 함(CalculatorPage.tsx). 화면 재확인은 안 함 → 확인 필요.

### 남은 문제·확인 필요
- 서버가 처음 보내는 /calculator HTML에는 차종 상자 대신 회색 틀이 나옴(내 차 카드가 번쩍 바뀌는 걸 막으려는 의도). 제목·설명·h1은 서버 HTML에 있음. 리드 판단 필요.
- 위 3개 부품이 모두 쿠팡 조회에 실패하고 링크도 없으면 고지와 연식 안내만 남음(드묾, 그대로 둠).
- 쏘렌토 디젤 엔진오일 검색에 다른 세대(쏘렌토 R) 세트가 둘째로 섞일 수 있음(상품명에 세대 코드 없음).
- 위 P2 수정 후 브라우저 재확인은 안 함 → 확인 필요.
- next.log의 '[gas:event] unknown action: event'는 기존 기록 기능 쪽(SR-004와 무관).
