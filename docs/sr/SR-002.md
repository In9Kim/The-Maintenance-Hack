# SR-002 탭 개편(A안) + 정비 탭 + 알림함 + 더보기

- 요청: 2026-11-28 사장님 피드백 8·9·11~14번, 탭 A안 결정
- 상태: 승인 대기
- 규모: 중간 (개발팀 3개, 파이프라인 1회)

## 약점 먼저
- 알림함은 **이 폰에 받은 알림만** 쌓여요. 다른 폰에서 받은 알림, 이번 오픈 전에 받은 알림은 안 보여요. (서버에 쌓으면 해결되지만 로그인·저장 공간·개인정보 처리방침 수정이 따라와서 이번엔 안 함)
- 알림 자체가 로그인한 사람만 켤 수 있어서, 로그인 안 한 사람의 알림함은 늘 비어 있어요. 빈 화면엔 "로그인하고 알림 켜기" 한 줄만.
- '마이' 탭 이름이 사라져서, 로그인·로그아웃·탈퇴 위치를 사장님이 처음 한 번은 찾아야 해요 (더보기 맨 위에 둠).
- 진행 막대는 지금 있는 교체 주기 숫자로 그려요. 주기 정보 없는 부품(브레이크 패드·배터리 등)은 막대 없이 "기록 필요"로 남아요.

## 공통 원칙
- 글 최소, 390px에서 단어 중간 줄바꿈 없게, 전문용어 없이, 빈 항목 숨김.
- 등록한 차를 다시 고르게 하지 말 것.
- 쿠팡 상품 근처 파트너스 고지(AFFILIATE_TEXT) 유지.
- 다른 앱(마이클 등) 디자인·그림·문구 복제 금지. 구성만 참고.
- 기존 주소는 그대로 살림: /my (정비 탭), /info, /privacy, /check, /recalls, /shop-card, /calculator. 푸시 알림이 여는 /my 도 그대로.

## 항목

### 1. 아래 탭 5개 (A안)
- 현재: 홈 · 견적서 · 정비소 · 마이 (4개)
- 변경: **홈 · 정비 · 견적서 · 정비소 · 더보기**
  - 정비 = /my (내 차 정비 화면). /cars/[차]/recalls 같은 내 차 화면에서는 '정비'에 불.
  - 더보기 = 새 화면 /more. /info·/privacy·/check·/recalls(전체)·/shop-card·/calculator 에서는 '더보기'에 불.
  - 홈 = / 와 /cars (차종 페이지).
- 컴퓨터 화면 위 메뉴(Header NAV)도 같은 순서로 맞춤.
- 완료 기준: 390px에서 탭 글자 5개가 한 줄, 줄바꿈 없음. 위 주소마다 맞는 탭에 불(차 리콜 페이지 '마이' 불 문제 해결).

### 2. 정비 탭 (/my 다듬기)
- 차 카드 아래 부품 목록에 **부품마다 진행 막대** 한 줄: 지난 교체부터 지금까지 얼마나 썼는지(ratio). 색: 여유 초록, 곧 주황, 지남 빨강. 막대 오른쪽에 지금 문구("약 3,000km 남음").
- 순서: 지남 → 곧 → 여유 → 기록 필요 (지금 정렬 그대로).
- '기록 필요' 부품은 막대 없이 지금처럼.
- 마이 화면에 있던 **로그인/계정 상자, 안내 목록, 도구(견적서 분석·부품 맞나요?·리콜 확인)는 더보기로 옮김**. 정비 탭에는 차·부품·기록만.
- 차를 아직 등록 안 했으면 지금처럼 '내 차 등록' (로그인 안내 포함).
- 완료 기준: K3 BD 등록 + 기록 2개 넣은 상태로 열었을 때, 기록 있는 부품마다 막대가 보이고 색이 상태와 맞음. 계정·안내 상자가 정비 탭에 없음.

### 3. 알림함
- 받은 교체 시기 알림을 **이 폰에 쌓아 둠** (서비스 워커가 푸시를 받을 때 폰 안 저장소(IndexedDB)에 제목·내용·주소·받은 시각 저장, 최근 50개, 90일 지난 건 지움).
- 홈 맨 위 오른쪽에 **종 아이콘**. 안 읽은 알림이 있으면 작은 점. 누르면 /inbox.
- /inbox: 최근 알림 목록(제목, 받은 날 "3일 전"). 누르면 알림이 가리키는 화면으로. 들어오면 모두 읽음 처리.
- 비어 있을 때: 로그인했으면 "아직 받은 알림이 없어요", 안 했으면 "로그인하면 교체할 때 알려 드려요" + 로그인 버튼(더보기 계정 상자로).
- 저장하는 것: 알림 제목·내용·주소·시각만 (차 이름·부품 이름 포함, 번호판·이메일 없음). 이 폰에만. 처리방침에 한 줄 추가.
- 완료 기준: 개발용으로 테스트 알림을 서비스 워커에 보냈을 때(또는 저장소에 직접 넣었을 때) 종에 점이 뜨고, /inbox에 쌓이고, 눌러서 이동, 다시 열면 점 없음.

### 4. 더보기 (/more)
- 위에서부터:
  1. 계정: 로그인 상자(로그인 전) 또는 '○○ 카카오 로그인 중 · 알림 켜기/끄기 · 로그아웃 · 탈퇴' (지금 마이의 AccountBox 그대로 옮김)
  2. 도구: 견적서 분석 · 부품 맞나요? · 리콜 확인 · 정비비 계산기 · 정비소 카드(/shop-card) — 쓰이는 화면이 실제로 있는 것만
  3. 안내: 데이터 출처·이용 안내 · 개인정보 처리방침 · 문의하기
- 한 줄 목록 + › 모양, 설명 글 없음.
- SR-001 남은 일(처리방침 링크 마이에만 있음) 여기서 해결.
- 완료 기준: 390x844 한 화면에 계정+도구가 보이고, 모든 줄이 실제 화면으로 이동(404 없음).
