# 정비핵 디자인 시스템 — "견적서 해독"

조건: 정비소 견적에 당황한 일반 차주가 믿고 쓸 수 있는, 깔끔하고 신뢰감 있는 도구.
시안 비교: `design-directions.png` (A 견적서 해독 / B 도로표지판 / C 다크 정돈형)

## 핵심 아이디어

정비핵이 하는 일은 **견적서를 부품값과 공임으로 나눠 다시 쓰는 것**이다.
그래서 화면의 주인공은 "영수증처럼 정리된 비용 표"다. 공식센터 금액은 빨간 취소선, 셀프 금액은 남색, 아끼는 돈은 초록 굵게.
대담함은 이 영수증 한 곳에만 쓰고, 나머지는 조용하고 단정하게 둔다.

## 글꼴

- **Pretendard Variable** 한 가족 (본문·제목 모두). 동적 서브셋 CDN, `font-display: swap`.
- 숫자는 항상 `font-variant-numeric: tabular-nums` — 금액 열이 자리 맞춰 정렬되게.
- 한글 줄바꿈: 제목·문단 모두 `word-break: keep-all` (단어 중간에서 끊지 않음).

## 간격·모양

- 4px 단위: 4 · 8 · 12 · 16 · 20 · 24 · 32 · 48 · 64
- 휴대폰 좌우 여백 20px, PC 본문 최대 폭 1080px (긴 글은 680px)
- 모서리: 입력·버튼 10px, 카드 14px, 배지 999px. 그 외 없음
- 그림자: 기본 없음(테두리로 구분). 떠 있는 요소(하단 고정 바)만 `0 -4px 16px rgba(20,33,61,.08)`
- 터치 대상 최소 44px

## 컴포넌트 규칙

| 컴포넌트 | 규칙 |
|---|---|
| 버튼 | 주요: save 초록 바탕·흰 글자. 보조: 흰 바탕·line 테두리·ink 글자. 한 화면에 주요 버튼 1개 |
| 차종 선택 | 브랜드 → 차종 2단 선택 + "정비 비용 보기". 홈 첫 화면에 항상 |
| 영수증 카드 | 항목별 행(공식센터 취소선 / 셀프) + 점선 아래 "아끼는 돈". 아래 가장자리 톱니 모양 |
| 비용 표 | PC는 표, **휴대폰은 행마다 카드로 바꿔** 가로 넘침 없음 |
| 구매 영역 | 규격 확인 → 제휴 버튼(맞는 상품 있을 때만) → 공임나라. 대가성 문구는 버튼 **바로 위** |
| 배지 | 리콜 건수, 엔진 종류. 둥근 알약, 글자 13px |
| 링크 | ink 글자 + 밑줄(hover 시 save). 화살표 문자 붙이지 않음 |

## 움직임

사용자가 누른 것에만 반응: 버튼 누름(살짝 눌림), 펼치기/접기, 선택 후 결과 등장 1번.
스크롤마다 나타나는 효과 없음. `prefers-reduced-motion`이면 모두 끔.

## 문구

쉬운 말, 동사로 끝나는 버튼("정비 비용 보기", "규격 맞는 상품 보기"). 과장("최대 60%!") 대신 실제 금액 예시.
