- 사이트: https://maintenance-hack.wwe9459.workers.dev
- 기술: Next.js 15 (App Router) · Tailwind CSS · Cloudflare Workers 무료 플랜
- 작업 범위: 진단 → 디자인 방향 3안 비교 → 페이지 5종 개선 → 품질 점검
- 비교 이미지: `compare-home.png` (홈 첫 화면), `compare-mobile.png` (페이지 5종 첫 화면)

## 핵심 개선점 5가지

### 1. 첫 화면에서 바로 "내 차 정비비 얼마?"
일반 차주의 첫 질문은 "내 차 정비비가 얼마냐"입니다. 그런데 기존 첫 화면은 차대번호와 상품 링크를 둘 다 가진 사람만 쓸 수 있는 호환성 검사였습니다. 이제 첫 화면 가운데에 브랜드·차종 선택을 두어, 고르고 버튼 한 번이면 그 차의 비용 페이지로 이동합니다. 휴대폰 기본 선택창을 써서 화면 크기와 상관없이 엄지로 고를 수 있습니다. 호환성 검사는 홈 아래로 옮겨 그대로 남겼습니다.

### 2. 휴대폰에서 사라지던 가격을 되찾음
차종 상세 페이지의 소모품 표가 375px 화면을 넘어서, 페이지의 핵심인 가격 열이 휴대폰에서 아예 보이지 않았습니다. 휴대폰에서는 항목마다 카드(이름·규격 / 공식센터 가격 · 직접 구매 가격)로 바꾸고, PC에서는 표를 유지했습니다. 엔진이 두 개인 차종은 탭으로 나눠 한 번에 한 엔진만 보이게 해서 페이지 길이도 줄였습니다.

### 3. 숫자가 어디서 왔는지 보이는 '영수증'
모든 금액을 영수증 한 장으로 통일했습니다. 공식센터 금액은 회색 취소선, 직접 구매 금액은 남색, 아끼는 돈은 초록 큰 글씨입니다. 빨간 취소선과 비교한 뒤, 덜 공격적인 회색을 골랐습니다. 영수증 아래에는 "공임나라 표준 공임 · 부품가 2026년 11월 시세 기준"처럼 출처를 표시했고, 홈의 예시 카드도 지어낸 숫자가 아니라 실제 데이터(쏘렌토 엔진오일)에서 가져왔습니다.

### 4. 정직한 제휴 링크 구조
"규격이 정확히 맞는 상품만 링크한다"는 원칙에 맞춰, 규격 확인 없이 쿠팡 검색 결과로 보내던 링크를 모두 뺐습니다. "검증된 최저가" 같은 틀린 표현도 같이 뺐습니다. 규격을 확인한 상품은 데이터 파일에 넣기만 하면 차종·부품·계산기 화면에 자동으로 나타납니다. 대가성 문구는 공정위 추천·보증 심사지침에 맞춰 링크 바로 위에 확정 표현으로 두었습니다. 클릭 추적(쿠팡·공임나라·리콜센터)은 그대로 기록됩니다.

### 5. 바꾸지 말아야 할 것은 지키고, 수치로 확인
검색에 이미 등록된 주소 357개는 하나도 바꾸지 않았고, 모두 정상으로 열리는 것을 확인했습니다. 구글시트 저장, 리콜 자동 수집, 유입 꼬리표(`?from=`), 관리자 화면도 그대로 동작합니다. 무료 플랜 한도(워커 3MiB) 안에서 용량은 오히려 1,561KB에서 1,536KB로 줄었습니다. Lighthouse 접근성은 모든 페이지 100(전 89~96), SEO도 모든 페이지 100이 됐고, 테스트 47개도 모두 통과했습니다.

## 작업 과정

1. **진단:** 휴대폰·PC 화면 14장과 Lighthouse 10회 측정으로 문제 13개를 정리했습니다 (`before/README.md`).
2. **방향 결정:** 3안 시안을 비교해 '견적서 해독' 방향으로 정하고 디자인 규칙을 문서로 남겼습니다 (`design-directions.png`, `DESIGN.md`).
3. **페이지 개선:** 홈 → 차종 상세 → 부품 → 계산기 → 리콜 순서로, 휴대폰 화면부터 만들었습니다.
4. **품질 점검:** Lighthouse 전후, 워커 용량, 테스트, 클릭 추적, 주소 전체를 확인했습니다 (`QA.md`).
5. **정리:** 개선 후 화면을 캡처하고 전후 비교 이미지를 만들었습니다 (`after/`).
